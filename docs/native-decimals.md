# Native currency precision

`decimals` is the exponent in `1 whole native unit = 10^decimals base units`. It belongs to the currency, not the address family. eCash is the useful counterexample: XEC has two decimal places despite sharing Bitcoin's UTXO ancestry. Avalanche here means AVAX on the C-Chain; this metadata does not describe its X/P chains.

These references were checked on 2026-09-05. Tests pin the values independently of the classes. No network request is needed at runtime or during tests.
