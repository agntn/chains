The C-Chain only, chain 43114. Avalanche's X and P chains use a different address format, and this class says nothing about them. Same for `decimals`: 18 is AVAX on the C-Chain.

## Address format

The EVM format, shared by every EVM chain here: `0x` and 40 hex digits, any case. An address that fits Avalanche C-Chain fits the other thirteen EVM chains too, and [identify](/guide/identify) says so rather than picking one. The EIP-55 checksum, the one carried in letter case, isn't verified.

```ts
import { getChain } from "@agntn/chains";

const chain = getChain("avax");
chain.assertAddress("0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984"); // returned unchanged
chain.chainId; // "0xa86a"
chain.caip2; // "eip155:43114"
```

## Spellings

`avalanche`, `avax`, `Avalanche C-Chain`. The key is `avalanche`, the rest resolve through `getChain`.
