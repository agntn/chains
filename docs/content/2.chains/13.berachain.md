Chain 80094. The key is `berachain`, the ticker `bera` is an alias, same rule as everywhere else here.

## Address format

The EVM format, shared by every EVM chain here: `0x` and 40 hex digits, any case. An address that fits Berachain fits the other twelve EVM chains too, and [identify](/guide/identify) says so rather than picking one. The EIP-55 checksum, the one carried in letter case, isn't verified.

```ts
import { getChain } from "@agntn/chains";

const chain = getChain("bera");
chain.assertAddress("0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984"); // returned unchanged
chain.chainId; // "0x138de"
chain.caip2; // "eip155:80094"
```

## Spellings

`berachain`, `bera`, `Berachain`. The key is `berachain`, the rest resolve through `getChain`.
