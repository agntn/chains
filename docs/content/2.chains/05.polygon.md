Polygon PoS, chain 137. The native token is POL now, and `matic` still resolves because half the configs in the world still say it.

## Address format

The EVM format, shared by every EVM chain here: `0x` and 40 hex digits, any case. An address that fits Polygon PoS fits the other twelve EVM chains too, and [identify](/guide/identify) says so rather than picking one. The EIP-55 checksum, the one carried in letter case, isn't verified.

```ts
import { getChain } from "@agntn/chains";

const chain = getChain("matic");
chain.assertAddress("0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984"); // returned unchanged
chain.chainId; // "0x89"
chain.caip2; // "eip155:137"
```

## Spellings

`polygon`, `matic`, `pol`, `Polygon PoS`. The key is `polygon`, the rest resolve through `getChain`.
