Fantom Opera, chain 250, with the one public RPC the class ships as a default.

## Address format

The EVM format, shared by every EVM chain here: `0x` and 40 hex digits, any case. An address that fits Fantom Opera fits the other thirteen EVM chains too, and [identify](/guide/identify) says so rather than picking one. The EIP-55 checksum, the one carried in letter case, isn't verified.

```ts
import { getChain } from "@agntn/chains";

const chain = getChain("ftm");
chain.assertAddress("0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984"); // returned unchanged
chain.chainId; // "0xfa"
chain.caip2; // "eip155:250"
```

## Spellings

`fantom`, `ftm`, `Fantom Opera`. The key is `fantom`, the rest resolve through `getChain`.
