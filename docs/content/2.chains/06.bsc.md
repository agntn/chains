BNB Chain, chain 56. The key is `bsc`, the old name, because nobody types `bnbchain` from memory. It works anyway.

## Address format

The EVM format, shared by every EVM chain here: `0x` and 40 hex digits, any case. An address that fits BNB Chain fits the other twelve EVM chains too, and [identify](/guide/identify) says so rather than picking one. The EIP-55 checksum, the one carried in letter case, isn't verified.

```ts
import { getChain } from "@agntn/chains";

const chain = getChain("bnb");
chain.assertAddress("0x1f9840a85d5aF5bf1D1762F925BDADdC4201F984"); // returned unchanged
chain.chainId; // "0x38"
chain.caip2; // "eip155:56"
```

## Spellings

`bsc`, `bnb`, `binance`, `bnbchain`, `BNB Chain`. The key is `bsc`, the rest resolve through `getChain`.
